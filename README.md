# Scaner-Tiguero-
Scaner de vulneravilidades en una IP en una web, usted elige el nombre del dominio o ip y el script busca vulneravilidades en esa web alimentándose dela base de datos de nmap, el script funciona en termux y linux


comandos :
pkg install python (termux )


sudo apt install python3 (Linux)


git clone https://github.com/Papuhacker2/Scaner-Tiguero-

cd Scaner-Tiguero-

 python l7.py

Y listo, Ya puedes escanear las webs que quieras.
